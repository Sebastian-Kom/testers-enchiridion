# Contributing

Improvements to the book and map are welcome. Keep the chapters short, direct, and useful to testers. Preserve their humor and the author's voice wherever possible.

For a map connection, name the Epictetan concept, chapter number, and testing concept. Explain briefly what connects them, or why the existing connection is misleading. These links are interpretations, not a fixed classification of Epictetus.

For a source correction, cite the historical edition and printed page. Distinguish an exact quotation from a modern adaptation. Avoid silently replacing Carter's wording with a later revision.

For a text or code change, edit the canonical files identified in the README, rebuild the generated website and PDF when affected, and run `python3 scripts/check.py`. Describe the reason for the change and how it was checked. Do not edit only the generated copy in `docs/`.

Include only material you have permission to contribute. Contributions to the original modern material are offered under this project's CC BY-SA 4.0 license. Clearly identify historical or third-party material that has a different status.

Open an issue for discussion or submit a pull request. A small, focused change is easier to review than a broad rewrite.
